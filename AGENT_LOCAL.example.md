# Entorno local para agentes

Este archivo documenta el formato de `AGENT_LOCAL.md`. Copiarlo localmente, completar rutas válidas para la máquina y no agregar device serials ni secretos.

```text
PYTHON_EXE = <ruta-absoluta-a-python>
ADB_EXE = <ruta-absoluta-a-adb>
SCRCPY_SERVER_PATH = <ruta-absoluta-a-scrcpy-server>
```
